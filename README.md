# Alejandro Gómez · Portafolio UX/UI

Sitio estático (HTML, CSS y JavaScript) publicado en https://alejoogmz.github.io

- `index.html`, `proyectos.html`, `sobre-mi.html`, `experiencia.html`, `404.html`
- `casos/`: páginas de los casos, generadas con `python3 _build/build_case.py <caso>` a partir de `_build/casos/<caso>.py`
- `js/i18n-en.js` y `js/en/`: textos en inglés
- `_build/`: herramientas de trabajo; GitHub Pages no publica carpetas que empiezan con guion bajo
